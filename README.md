### 🛠 Mon Stack Technologique & Capacités d'Intégration

Je travaille avec une variété de technologies pour construire des solutions de bout en bout, allant du développement web à la création de jeux vidéo et l'automatisation.

*   **🐍 Python :** Mon langage de prédilection pour l'automatisation de tâches complexes, la manipulation de données, et l'intégration avec des APIs (notamment l'API GraphQL de GitHub). Je l'utilise pour créer des flux de travail autonomes et intelligents.
*   **🌐 JavaScript & Technologies Web (HTML5/CSS3) :** Utilisés pour le développement frontend et la création d'interfaces utilisateur interactives et réactives.
*   **🎮 Unreal Engine (C++ & Lua) :** Expérience dans le développement de jeux vidéo, en utilisant la puissance du C++ couplée à la flexibilité de Lua pour la logique de jeu.
*   **⚙️ CI/CD & Automatisation (GitHub Actions) :** Fortes compétences en mise en place de pipelines CI/CD. J'utilise GitHub Actions pour automatiser les tests, le déploiement et même la mise à jour dynamique de ce profil (via des scripts Python).
*   **🐳 Outils DevOps (Docker, Git) :** Utilisation de Docker pour la conteneurisation des applications garantissant des environnements cohérents, et de Git pour un versionnage efficace et la collaboration.
