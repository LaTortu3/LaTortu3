### 🛠 Mon Stack Technologique & Compétences

Je suis spécialisé dans la conception de solutions allant du backend d'automatisation jusqu'au développement de gameplay. Voici mes compétences détaillées :

* **Python :** Mon langage de prédilection pour l'automatisation de tâches, la création de scripts CI/CD, et l'intégration avec des APIs complexes (ex: GraphQL pour GitHub). J'utilise souvent Python pour lier différents systèmes entre eux.
* **JavaScript & React :** J'utilise l'écosystème JS pour construire des interfaces web dynamiques et responsives. La flexibilité de React me permet de concevoir des portfolios et des outils internes interactifs.
* **Lua & C++ :** Ces langages sont au cœur de mon travail sur **Unreal Engine**. J'utilise C++ pour l'architecture système robuste et Lua pour l'implémentation rapide et flexible de la logique de gameplay.
* **DevOps & CI/CD :** J'intègre des pipelines d'intégration continue via **GitHub Actions** pour assurer la qualité du code et déployer automatiquement mes scripts (comme la mise à jour dynamique de ce README).
